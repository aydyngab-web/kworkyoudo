A portfolio repository focused on practical AI automation, API integrations, webhook-driven workflows, and reliable task orchestration.

## What this project demonstrates

- REST API integration patterns
- Async Python workflows
- Webhook/event-driven architecture
- LLM API integration patterns
- Retry, timeout and error-handling strategies
- Structured logging and health checks
- Environment-based secret management
- PowerShell-friendly local automation

## Repository modules

