Engineering areas demonstrated:

- Router/network configuration research
- SSH-based administration
- Proxy/VPN routing concepts

- Device-specific routing/exclusion rules

This is presented as infrastructure experience, not as a public exploit or bypass tutorial.

## Security rule for portfolio publication

Never publish production `.env` files, API keys, tokens, private keys, customer databases, logs containing private data, or live infrastructure credentials. Public examples must use placeholders and sanitized sample data.
